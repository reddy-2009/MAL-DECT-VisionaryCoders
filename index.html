⌘  CYBERSECURITY DEFINITIONS

A beginner-friendly MAL-DECT glossary

Malware

Any software designed to harm, disrupt, spy on, or gain unauthorised access to a device.

Virus

Malware that attaches to a file or program and spreads when that host is run.

Worm

Malware that can spread across networks or devices automatically, without a host file.

Trojan

Malware disguised as a legitimate app, file, game, or update to trick a user into running it.

Ransomware

Malware that locks or encrypts data and demands payment for restoration.

Spyware / Keylogger

Malware that secretly collects activity or records what a user types.

Phishing

A fake message or website that tries to steal passwords, OTPs, payment details, or personal data.

Firewall

A security control that monitors and blocks unwanted network connections.

Antivirus

Security software that detects, blocks, quarantines, or removes known and suspicious threats.

Quarantine

A safe isolation area for suspicious files, preventing them from running while they are reviewed.

Two-factor authentication

An extra sign-in step, such as an authenticator approval, that helps protect an account beyond its password.

Static analysis

Examining a file’s properties and code patterns without executing it—the approach used by MAL-DECT.
